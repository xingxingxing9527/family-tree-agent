# 快速新建反馈与婚姻组布局设计

## 目标

修复两处已复现的界面问题，同时保持现有亲属数据和关系推导逻辑不变：

- “快速新建母亲”等操作打开页面上方表单后缺少可见反馈。
- 家谱树允许无关人物卡片插入配偶与婚姻节点之间，造成关系误读。

## 交互设计

“快速新建父亲/母亲/配偶/子女”的按钮文案改为“新建人物并设为父亲/母亲/配偶/子女”，明确该操作会创建新人。按钮触发后，页面自动滚动至快速新建区域，并将焦点放到“姓名”输入框。选择已有人员仍通过“添加……并预览”完成，不改变当前候选选择。

## 布局设计

在 ELK 初始布局和现有人物卡片防重叠处理之上，将同一行内由婚姻边连接的人员和婚姻节点视为一个连续布局组。组内保持“配偶—婚姻节点—配偶”的连线邻接关系；无关人物可以排在组的两侧，但不能落在任一配偶与婚姻节点的水平连线区间内。继续保持最小水平间距和原有代际纵向位置。

## 验收标准

- 点击“新建人物并设为母亲”后，快速新建区域进入视口，姓名输入框获得焦点。
- 李腾飞、可可和两人的婚姻节点连续排列，李格非不位于任何一条配偶连线的两个端点之间。
- 人物与婚姻节点之间仍无矩形重叠，既有关系录入、再婚和树视角行为不退化。
