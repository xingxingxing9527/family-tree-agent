# 家谱树上下文编辑设计

## 目标

让家谱树成为人物资料和亲属关系的直接入口：点击人物可在不离开树的情况下查看、编辑资料和增补亲属；点击婚姻节点、夫妻横线或亲子竖线可进入对应关系编辑。

## 交互模型

- 家谱树保持为主画布，桌面端使用右侧抽屉；窄屏使用底部抽屉。
- 点击人物节点时高亮人物并打开人物详情。抽屉复用现有 `PersonDetail`、`PersonEditor` 和 `FamilyRelationsPanel`，支持编辑人物、新增父母/配偶/子女、设置视角和发起提问。
- 点击婚姻联合节点或人物与该节点之间的横线时打开婚姻关系编辑，明确展示双方、状态及起止日期。
- 点击家庭联合节点到子女的竖线时打开亲子关系编辑，明确展示该子女及当前父母，支持补充、更正或移除亲子关系。
- 点击空白区域、关闭按钮或按 `Escape` 关闭抽屉；切换选中对象时替换抽屉内容。

## 数据与安全

- 树投影直接返回 `parentIds`、`childIds` 和 `marriageId`，界面不得解析联合节点字符串 ID 推断业务实体。
- 点击只改变界面选中状态，不直接写入数据。
- 所有关系修改继续走“结构化预览、冲突校验、管理员确认、可撤销写入”。
- 错误婚姻的更正和删除必须使用独立的更正/删除意图，不能伪装成离婚历史。
- 确认写入后刷新人物详情与树投影，并尽量保留当前缩放、平移和有效的选中对象。

## 验收

- 人物、婚姻和亲子关系三类点击均能打开正确对象的抽屉，并有明显选中高亮。
- 抽屉内的编辑和快捷新增能够完成现有预览确认流程，写入后树同步更新。
- 婚姻关系可更正配偶、日期和状态，也可删除错误记录；亲子关系可补充、更正和移除。
- 键盘可用 `Enter`/`Space` 打开节点，`Escape` 关闭抽屉；无选择时不出现空抽屉。
