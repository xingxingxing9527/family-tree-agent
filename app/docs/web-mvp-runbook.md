# 家谱智能体 Web MVP 运行说明

当前交付是网页应用，不提供 Windows 安装包。开发验证默认只监听 `127.0.0.1`，浏览器和服务端可以先运行在同一台电脑上；等交互和业务逻辑稳定后，再决定购买或租用服务器。

## 开发与验收

在 `app` 目录安装依赖后，可使用以下命令：

```powershell
npm run dev:web
```

开发页面由终端输出地址提供。完整 Web 验收使用：

```powershell
npm run verify:web
```

该命令依次执行类型检查、单元与集成测试、Web 构建、浏览器端闭环测试和性能门禁。浏览器测试覆盖响应式导航、五人家谱、离婚与再婚、证据化问答、中文 Excel 关系导入与幂等重导、备份恢复和撤销；性能门禁覆盖人物搜索、人物详情、家谱树投影、亲属关系计算和千人 Excel 导入。

## 构建与启动

```powershell
npm run build:web
npm run start:web
```

服务默认监听 `127.0.0.1:8787`。可通过环境变量调整运行参数：

| 环境变量 | 用途 | 默认值 |
|---|---|---|
| `FAMILY_AGENT_PORT` | Web 服务端口 | `8787` |
| `FAMILY_AGENT_DATA_DIR` | 服务端数据、媒体和上传文件目录 | `.family-agent-data` |
| `FAMILY_AGENT_WEB_ROOT` | 已构建网页目录 | `out/web` |
| `FAMILY_AGENT_OPENAI_API_KEY` | 在线模型密钥，仅服务端读取 | 未配置 |
| `FAMILY_AGENT_MODEL` | 在线问答所用模型名称，需与密钥权限兼容 | `gpt-4o-mini` |

未配置模型密钥或模型暂时不可用时，人物、关系、家谱树、结构化关系查询、Excel、备份和撤销仍应工作；对话入口应明确提示模型不可用，不能伪造答案。

## 数据与部署边界

Web 版本的数据保存在运行服务的机器上，不依赖用户电脑安装客户端。请定期从“设置与数据”创建备份，并把下载的 ZIP 保存到独立位置；恢复前必须先通过页面校验，再确认替换目标家谱。

当前 MVP 没有多用户账号、公网身份认证和权限隔离，因此不要直接把端口暴露到公网。若后续部署到云服务器，至少需要在反向代理层加入 HTTPS、登录认证、访问日志、定时备份和监控，再邀请真实家族成员使用。
